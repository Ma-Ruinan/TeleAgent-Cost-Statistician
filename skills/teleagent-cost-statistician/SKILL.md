# TeleAgent执行过程统计

以完整数据集和本次测试工作空间为范围，输出每次运行的九项指标、题目与对象均值，以及有证据定位的过程问题。日志只读，结果保存在本地。

先读 [日志字段](references/log-schema.md) 和 [输出口径](references/output-contract.md)。脚本使用Python 3.10及以上版本的标准库，无需Office或其他Skill。

## 自动执行与范围

- 收到收集指令后自行发现和执行，不向用户确认路径、账号、题号、测试次数或结果目录。核实指Agent读取文件和日志取证，不要求人工回复。无法可靠完成的事项集中写入最终结果，继续能够独立完成的部分；源字段不兼容、权限不足或缺少日志时记录具体原因，不猜测数值或无限重试。
- 数据集目录应为包含各维度的根目录。递归读取问题描述.txt、question.txt、prompt.txt；其他格式由Agent读取后整理为任务清单。题目数、维度数和运行次数从本次数据确定，不固定为四题或两次。题号重复时用维度与题号组成唯一ID；完全相同的题目出现在多个维度且无法从记录区分时列为无法确定。
- 用户提供的测试工作空间是收集边界，包含该目录及其子目录，不自动扩大到父目录，也不以最近修改时间只取最后一次。若提供多个工作空间，全部纳入。空间内只统计与数据集明确关联的测试，其他题目、后台会话单列排除。
- 默认不传 --date，收集范围内匹配题目的全部历史运行及继续段。用户填写不限定等同省略。只有明确具体日期时才传 --date YYYY-MM-DD；按独立测试首次提交日期筛选，后续继续段完整保留。小时区间和模糊时间尚无脚本筛选能力，遇到时交付该条件无法应用的说明，不将其当作不限定而扩大范围，也不自行猜测区间。
- 未提供工作空间时，从本对象的本地日志枚举实际工作目录，以完整题目匹配发现所有相关空间，作为多个 --workspace 传入，并列明发现范围；不自行猜测哪一批是本次，也不悄悄丢弃较早运行。未提供数据集且无法从当前任务找到唯一明确目录时，交付无法启动的原因和发现的候选，不等待用户确认。
- 未提供结果目录时，在当前Agent任务目录下创建统计结果/TeleAgent/YYYYMMDD-HHMMSS，避免覆盖其他批次。由Agent补全脚本所需的 --workspace 和 --output，不将脚本必需参数变成对用户的追问。

## 定位和采集

1. 按日志字段说明枚举当前用户 .local/share/TeleAgent/users 下的账号数据库。存在多个数据库时，逐个只读检查工作空间与完整题目，自行确定来源并传入 --db；无法唯一归属的来源分别记录，不任取一个，也不要求用户选择账号。工作空间名称或目录时间不替代消息归属。
2. 用完整题目与实际用户消息关联。默认仅忽略空白。改写题目需Agent读取消息、附件和题目文件核实后生成 --mapping，不用相似度直接归属。证据仍不足的记录保留排除原因，题目未匹配不填零。
3. 执行采集，默认不加日期参数：

```powershell
python <skill目录>/scripts/collect.py --tasks "完整数据集根目录" --workspace "本次测试工作空间" --db "账号数据库路径" --output "本地结果目录"
```

日志源位于默认位置时可省略 --db 或 --logs-root。可重复给出 --workspace 和 --session。时区默认Asia/Shanghai；日期明确时再增加 --date YYYY-MM-DD。题目清单通过 --task-manifest 输入。不要重新运行受测任务。

## 子Agent执行

采集器递归关联主任务实际委派的各层子Agent。原始题目只匹配主任务，子任务按委派标识继承本次测试归属；不要将它们当作独立题目重新匹配或排除。恢复同一子会话时只纳入本次委派窗口的记录；并行耗时不累加。具体关联字段见日志字段说明。

读取agent_coverage检查子日志是否齐全，结合agent_links与Agent明细复核层级、来源和去重情况。缺少子日志时不把主会话的零次搜索当作完整任务总数，也不根据父摘要推算Token或工具数。

## 复核和交付

读取执行数据JSON，核对全部题目、缺失题目、实际工作空间、执行次数和排除记录。完整重提保留为新的独立测试，继续指令保留为原测试后续段；逐次统计并计算均值，不能只取最后一次或成功一次。

缺失数据保持空值。工具错误包括内部标记及非零退出码；LLM完成调用数仅计已完成且有用量的调用，模型失败重试单列。页面已完成但实际拒答等补充观察，通过 --observations 保留已取得的用户或页面证据；没有页面访问能力时不要求用户补图，也不编造回复。

在Word中按题记录具体问题、已观察影响和日志证据。以数值和事实为主，通用口径集中说明一次；正常任务不重复添加保护性声明，必要的异常、缺失和特殊条件简短说明。需要补充分析时，写入按测试ID组织的段落数组，再运行：

```powershell
python <skill目录>/scripts/report.py "本地结果目录/TeleAgent_执行数据.json" --analysis "补充观察.json" --output "本地结果目录"
```

最终交付 `TeleAgent_过程指标统计.xlsx`、`TeleAgent_过程问题与采集方法.docx`，保留 `TeleAgent_执行数据.json`。耗时使用时分秒，Token以万为单位；均值和有效样本数逐指标列出。交付时列明完整数据集、实际工作空间、已应用的日期条件、覆盖题数、未匹配题目、保存位置及未完成事项。无法产生统计文件时保存本地采集说明并说明原因，不宣称采集完成。真实日志和运行结果保持在本地。

题目来源统一为综合能力、AlphaData、DeepInsight，优先读取任务清单的 dataset_source，其次从 dataset、dimension 或题目源文件路径识别。清单模式应保留来源信息；无法确认时记录未识别，不根据题目内容猜测。Excel 在题号左侧列出题目来源，JSON 保留 dataset_source，便于跨对象合并。
