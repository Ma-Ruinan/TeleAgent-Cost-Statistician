# TeleAgent执行过程统计

针对用户提供的题目集和工作目录，找到本对象对应的执行记录，输出每次测试的九项过程指标、题目与对象均值，以及有证据定位的过程问题。读取应用日志时只读；报告写入用户指定的结果目录。

先读 [日志字段](references/log-schema.md) 和 [输出口径](references/output-contract.md)。脚本使用Python 3.10及以上版本的标准库，可独立运行，无需Office或其他Skill。

## 定位和采集

1. 核实题目集、批次范围和日志来源。题目数、题号、测试日期和运行次数从本次数据确定，不固定为四题或两次。单个项目路径仅是线索时，检查同批次其他项目；确认后用父目录、多个 --workspace 或 --session 限定范围。
2. 读取完整题目与实际用户消息关联。默认发现目录中的问题描述.txt；其他文件格式可整理为含id、name、prompt的任务清单，通过 --task-manifest 输入。无法完整匹配时核实消息，再用 --mapping 指明关联。
3. 在当前任务的本地结果目录运行采集。下面的路径替换为本次真实路径，日期可省略，省略时不截断历史测试。

```powershell
python <skill目录>/scripts/collect.py --tasks "题目集目录" --workspace "本批工作目录或父目录" --db "账号数据库路径" --date YYYY-MM-DD --output "本地结果目录"
```

可重复给出 --workspace 和 --session。默认时区为Asia/Shanghai，必要时使用 --timezone。日志源位于默认用户目录且已确认时可省略源参数。不会自动重新运行受测应用的任务。

## 复核和交付

读取生成的执行数据JSON，逐题检查结果状态、附加条件、执行分段、用量字段、错误、模型重试、登记文件和排除记录。追加继续保留为原测试后续段；完整重新提交产生新记录。检查所有独立运行，不能只保留最后一次或成功一次。

缺失数据保持空值。工具错误包括内部标记及非零退出码；LLM完成调用数只计已完成且有用量的调用，失败重试单列。页面已完成但实际拒答等补充观察，通过 --observations 保留来源，不能以页面状态填补缺失用量。

在Word中说明每道题的具体问题及已观察影响，列明日志证据。需要补充分析时写入按测试ID组织的段落数组，再运行：

```powershell
python <skill目录>/scripts/report.py "本地结果目录/TeleAgent_执行数据.json" --analysis "补充观察.json" --output "本地结果目录"
```

最终交付 `TeleAgent_过程指标统计.xlsx` 与 `TeleAgent_过程问题与采集方法.docx`，保留 `TeleAgent_执行数据.json` 供回查。耗时使用时分秒，Token以万为单位；均值和有效样本数逐指标列出。人工补充的页面信息要注明来源，推断要有具体日志依据。真实日志和运行结果保持在本地，不因使用本Skill而获得对外上传授权。
